QUICK START:
  1. Read START_HERE.txt
  2. Copy qblot.env.example to qblot.env
  3. Edit qblot.env with IBM credentials
  4. Run: ./setup.sh
  5. Test: make test

QUICK COMMANDS:
  make help          Show all commands
  make status        Check pipeline status
  make test          Run test pipeline
  
  node qft-runner.js           Show help
  node qft-runner.js status    Check status
  node example-usage.js        Show examples
