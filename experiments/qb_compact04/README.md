# QB-COMPACT-04: shared batched cosine screening

CPU-only opt-in prototype, continuing QB03. Original normalized vectors retained for exact-score reranking. Full, gather, union, auto and single-pass lower-bound modes share one maximum-rank orthogonal frame, projected corpus and residual norms. The previous residual Cauchy-Schwarz upper/lower bounds hold for a contraction. Within a tile the kth largest lower bound is a valid lower bound on the global kth true score. Strict exclusion and numerical slack retain ties. Seeded modes compute exact pilot scores and cache projected panels when a single tile fits; otherwise recompute them. Lower mode requires one projection pass with no pilots. Union scoring shares a GEMM across adjacent queries; auto selects dense tiles for >=45% candidate density, or union GEMM when redundant products are at most twice the necessary pair count. Extra products are included in work accounting. Float64 bounds are engineering safeguards rather than interval certificates. Near-tied contenders, including those near the kth boundary, are rescored via deterministic math.fsum of rounded coordinate products after a BLAS-shape tie discrepancy was found. Eight final regression tests passed.
